For [[Blender]], name of each mesh affects how godot imports that segment.
# Suffixes
- `-noimp` : no iumport
- `-colonly` : Make this mesh a static body node
- `-loop` : For animation, godot makes this loop
- `-rigid` : Make this rigid body
