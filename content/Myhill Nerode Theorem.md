A requirement for a language to be a [[Regular Language]]
# Theorem
- Language $L$ 
- Pair of strings $x,y$, 
- A distinguishing extension $z$ has that $xz$, $yz$ belongs to $L$
- A [[Equivalence Relation]] $\sim_{L}$ on two strings $x \sim_{L} y$ if there is no distinguishing extension $z$ for them
- All strings can be divided into [[Equivalence Class]]
