A [[Burp Suite]] extension to edit [[JSON Web Token|JWT Token]].
# Usage
All JWT Tokens can be viewed in the Repeater tab of a request that has a JWT.

# Creating Keys
- RSA for RS256 hashes
- Symmetric for HS256 hashes
