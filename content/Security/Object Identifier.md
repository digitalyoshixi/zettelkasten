These are standard identifiers that identify an object by a persistent name.
Used in [[Extended Key Usage|EKU]], [[Simple Network Management Protocol|SNMP]]
# System
![[Object Identifier-20260830171704818.webp]]
### Example
```
1.3.6.1.5.5.7.3.1
```
- 1 : ISO
- 3 : Identified Organization
- 6 : [[Department Of Defense|DoD]]
- 1 : Internet related OID
- 5 : security mechanism
- 5 : Cryptography mechanism
- 7 : Public key infratructure x509
- 3 : Extended key usage
- 1 : Server authentication
