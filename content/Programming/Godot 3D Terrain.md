A [[Godot]] plugin for 3d terrain generation made by Tokisan Games.
# Installation
1. Asset Store
2. Terrain3D
3. Download
4. Plugins > Terrain3D > Enable
5. Add Terrain3D Node to world
6. Properties > Data Directory > Select Folder to use as data dir
