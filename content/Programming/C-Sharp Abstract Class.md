A [[C-Sharp Class]] that:
- Cannot be instantiated
- Can have abstract methods
- Can have concrete methods
```cs
abstract class Animal
{
	public int age;
	public abstract void sound();
	public void sleep()[
		Console.WriteLine("Zzz");
	]
	
}
```
