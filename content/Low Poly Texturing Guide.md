# Guide
1. Find a texture online
2. Load texture into model
3. Set textools to right texture size
4. Smart unwrap with island margin 0.05
5. Set text density to 1.0px/cm
6. In texture paint mode, set bleed to 8px
7. Draw with texture paint mode
8. Save texture, convert to pixel, use the next pixelated texture
