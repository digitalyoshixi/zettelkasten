# Project You're Proudest of
I am pretty happy about my mini compiler project for a C-like language (https://github.com/csecutsc/c-compiler) I did a while ago. it is able to parse arithmetic and string expressions and output to the console. The main motivation was to build the parser and learn IR to become better at reverse code engineering. Its part of this larger path i'm following called 'How to Become a Full Stack Reverse Engineer' (https://docs.google.com/presentation/u/1/d/1HLVUfbn9w7BXzYI437vF-yxEqujwLQp9brdIHhgTEv0/mobilepresent#slide=id.g40a958e53b_0_72). I spent two weeks learning compiler design from scratch consulting the LLVM docs, 'Crafting an Interpreter' and the dragon book. I was able to give a seminar on it at my university's systems programming club (https://docs.google.com/presentation/u/1/d/1HLVUfbn9w7BXzYI437vF-yxEqujwLQp9brdIHhgTEv0/mobilepresent#slide=id.g40a958e53b_0_72). I was also able to mentor my friend using what I learned from this project to get him a compiler job :D.

Hardest parts about this project (took the most time):
- Understanding parsing algorithms. I had to draw a few diagrams, even now I cannot recall how they work from head.
- Way too easy to go deep into rabbit holes as compiler development is a pretty mature field, there are a ton of resources online. I read a bit of one resource, moved to another one after I got bored haha. It was hard to stay focused on one thing when there might be something that explains it better.

This project is really worth doing because:
- Gives you insight on a few optimizations that languages actually do (Short circuiting, DCE, Inlining, All of that bit twiddling witchcraft)
- Lets you write much better parsers. I've wrote a ton of grammars for recursive descent parsers during hackathons.
- Opens up the door to niche research opportunities (actually compiler dev is not a sought after skill in industry, so academia is the only path haha). My professor is meeting with me tomorrow to discuss a research project for developing a functional language because of my related experience in compiler design!!
- Makes you much better at reverse code engineering if you are interested in that route. Knowing how things are built helps you break it apart. Also explains a lot of the mystery that bytecode virtual machines are doing.
