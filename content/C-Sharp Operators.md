# Unary
```cs
x++ // increment
x-- // decrement
!x // logical not
```
# Binary
```cs
x + y // addition
x - y // subtraciton
x * y // multiplication
x / y // division
x % y // modulus
x = y // assignment
x == y // equal to
x != y // not equal
x < y // less
x > y // greater
x >= y // geq
x <= y // leq
x && y // logical and
x || y // logical or
```
