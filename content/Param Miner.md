A burp suite extension to automatically brute force parameters of a request.
- Can be used to help with [[Web Cache Deception]] with cache buster
# Parameter Guessing
- Right click request >  Guess params
# CacheBuster
Adds a unique query string to every request you make, shows in `Logger` tab.
- Param Miner > Settings > Add Dynamic Cachebuster
