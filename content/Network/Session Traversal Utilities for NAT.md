A protocol by a local device to query what their public IP + [[Network Address Translation|NAT]] port is.
- Example: `203.0.113.5:52001`
Used to establish the iniital session between [[WebRTC]] [[Interactive Connectivity Establishment|ICE]] candidates.
Does not work on [[Symmetric Network Address Translation]]
