Phones that use [[IP Header|IP Frame]] to relay voice data represented by bits in data portion of IP packet.
- Should be setup in a separate [[Virtual Local Area Network|VLAN]]
# Port Guide
IP phones have three ports:
- Legacy [[Unshielded Twisted Pair|UTP]] cable for 100-Mbps Ethernet
- Wiring closet cable
- Extra cable
