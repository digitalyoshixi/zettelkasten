| Modifier    | Description                                 |
| ----------- | ------------------------------------------- |
| `public`    | Acessible to all classes                    |
| `private`   | Accessible to the same class                |
| `protected` | Accessible to same class or subclasses      |
| `internal`  | Accessible to the same [[C-Sharp Assembly]] |
